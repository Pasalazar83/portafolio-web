# Portafolio Web — HTML5 Semántico y CSS Flexbox

Laboratorio de la Unidad Didáctica **HTML5 y CSS Básico**, curso Ingeniería Web I.

Página de portafolio personal construida con:

- **HTML5 semántico**: `header`, `nav`, `main`, `section`/`article`, `footer` — un único `<main>` por página y `aria-label` en la navegación.
- **CSS Flexbox** (sin frameworks externos): de una columna en pantallas menores a 768px, a un layout de tres columnas en escritorio.
- **Formulario de contacto accesible**: cada campo con `<label for="">` asociado a su `id`.
